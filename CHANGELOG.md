# Changelog

| Date | Change | Details |
|------|--------|---------|
| 2026-05-04 | Add Campaigns tab for HCP Journey app | New `DemoCampaignController` creates journey campaigns (1 per country with Unaware→Advocate stages, all HCPs as members) and 7 marketing campaigns (email nurtures, webinars, congress follow-ups with Sent/Opened/Clicked/etc. statuses). Tagged via `External_ID__c = AFLSCE-Demo-Data-CAMP-*`. |
| 2026-05-01 | Remove template dependency from Action Plans | `DemoActionPlanBatch` no longer requires specific named templates in Final status. Uses any existing Final `ActionPlanTemplateVersion` to satisfy the required field, then replaces auto-created tasks with custom `KAM_TASKS` from `DemoAccountPlanData`. Added `Demo_Account_Plan` permission set with `ActionPlansUserAccess` and CRUD on AccountPlan, ActionPlan, etc. |
| 2026-05-01 | Planned visits for next 30 days | Visit creation now adds ~50 planned visits (Status=Planned) for today through today+30 days. Inserted as Completed first to bypass `ProviderVisitTrigger` email templates, ProviderVisit and product detailing created, then flipped to Planned. |
| 2026-05-01 | Organic visit distribution with phase-based weighting | Replaced per-week random weights with multi-week phases (3-6 alternating hot 1.6-2.5x and cold 0-0.4x streaks). Cumulative progress chart now shows realistic deviations from the target line instead of tracking it linearly. |
| 2026-05-01 | Measure type picker for Activity Plans | Added `getMeasureTypeOptions()` querying `ProviderActivityMeasureType` and `lightning-radio-group` on the Activity Plans tab. Primary measure type gets 90% of visit goals. Renamed tab from "Provider Activity Plans" to "Activity Plans". |
| 2026-05-01 | Channel picker for visit creation | Replaced activity-plan-goal-based channel distribution with a UI radio button group. `getChannelOptions` returns active `Visit.Channel` picklist values; `createVisits` accepts `primaryChannel` (90% of 600 yearly visits). Auto-defaults to "In-Person". Remaining 10% split evenly across other channels. |
| 2026-05-01 | Fix visit date clustering on Tue/Thu | Replaced pure LCG-based `pickVisitDates` with evenly-spaced base indices plus small random jitter, distributing visits across all 5 weekdays. |
| 2026-05-01 | Delete confirmation on all tabs | Added `window.confirm` dialog to all 10 `handleDelete` methods across all LWC tabs to prevent accidental data deletion. |
| 2026-05-01 | Expand major city HCPs to 20 | Added 160 doctors and 20 orgs across London, Paris, Berlin, Rome, Madrid, Tokyo, Seoul, São Paulo, Mexico City, Buenos Aires. Each major city now has 20 HCPs and 5-8 HCOs. |
| 2026-05-01 | Lower activity plan goals to 10–50 per HCP | Changed `goalValues` from 600/500/400… to 50/48/45/42/40…/12/10 for realistic per-HCP visit targets. |
| 2026-05-01 | Fix NPI uniqueness across batches | `buildNpiRecords` now accepts an offset parameter so each batch generates unique NPI numbers (batch 1 starts at 1000000000, batch 2 at 1000000030, etc.). Prevents "NPI value must be unique" errors when US providers are created in multiple batches. |
| 2026-05-01 | Batched visit deletion with unlock and error reporting | Replaced single `deleteVisits()` with `deleteVisitBatch()` that returns remaining count. LWC loops batches until done. Unlocks visits (Status→Planned) before delete, removes child ProviderVisitProdDetailing and ProviderVisit first, reports per-batch errors, and breaks if remaining count stops decreasing. Added UI warnings about disabling VisitLockHandler and RemoteSessionInvitationVisitHandler triggers before deleting. |
| 2026-05-01 | Per-country batched account/provider creation | Split `createAccountsAndProviders` into 5 separate Apex methods (`getCountryCodes`, `getDoctorCount`, `createOrgsForCountry`, `createDoctorsForCountry`, `createProvidersForCountry`, `createAffiliationsForCountry`) each running as a separate transaction. LWC loops through countries with batched provider (30) and affiliation (20) calls. Avoids SOQL 101 governor limits caused by LSC managed-package trigger overhead. Activity log shows per-country, per-batch progress in the UI. |
| 2026-05-01 | NPI records restricted to US providers only | `createProvidersForCountry` only creates HealthcareProviderNpi records when `countryCode == 'US'`. International providers skip NPI generation. |
| 2026-04-30 | Activity Plan & Visit troubleshooting guide | New `docs/ActivityPlan-Guide.md` documenting ProviderActivityMeasureType Category requirement, Visit object quirks (InstructionDescription tagging, TerritoryId+Channel for calendar, VisitSubmitDateTime for progress chart), VisitLockHandler delete blocking, timezone-aware scheduling, batch job behavior, and stuck job clearing (must reset both JobId and JobStatus). |
| 2026-04-30 | Move "Clear Stuck Job Status" to Provider Activity Plans tab | Moved `clearActivityPlanJobStatus()` from `DemoVisitController` to `DemoActivityPlanController`. Updated method to clear both `JobId` and `JobStatus` fields (clearing only JobStatus was insufficient when old JobId was stale). Removed button from visitSetup LWC, added to providerActivityPlanSetup LWC. |
| 2026-04-30 | Add Visits tab with territory-scoped visit creation | New `DemoVisitController` creates 3-6 completed Visits per weekday for the last 30 days with timezone-aware scheduling (8am-4pm local). Each Visit gets a ProviderVisit (with VisitSubmitDateTime for activity plan progress) and ProviderVisitProdDetailing records for Immunexis + Immunonco brands. Territory picker, delete with VisitLockHandler warning. |
| 2026-04-30 | Add Activity Plans tab with product-level goal measures | New `DemoActivityPlanController` creates TimePeriod, ActivityPlan, ActivityPlanTerritory, ProviderActivityGoal, and ProviderActivityGoalMeasure records per territory. Visit-level measures (In Person, Phone, Remote) split from NonProductGoal (60%). Product-level measures track Immunexis and Immunonco brands per country from ProductLevelGoal (40%), with `ProductList` linking to country-specific `LifeSciMarketableProduct` brand records. |
| 2026-04-30 | Rename DemoActivityPlanController → DemoAccountPlanController | The old `DemoActivityPlanController` (which creates AccountPlans + ActionPlans) was misnamed. Renamed to `DemoAccountPlanController` with methods `createAccountPlansAndActions` / `deleteAccountPlansAndActions`. `DemoActivityPlanDeleteBatch` → `DemoAccountPlanDeleteBatch`. Updated `activityPlanSetup` LWC and `DemoAccountPlanLocale` references. |
| 2026-04-30 | ProviderAffiliation FLS for Field Sales Representative | Added read access on all 18 ProviderAffiliation fields to the Field Sales Representative profile. Missing FLS caused "No such column 'RelatedAccountName'" error on the Affiliations tab. |
| 2026-04-30 | Affiliation OwnerId set to territory user | `DemoAffiliationHelper.createAffiliations()` now accepts `cityTerrMap`, resolves each doctor's territory via `UserTerritory2Association`, and sets `OwnerId` to the territory user. Previously all affiliations were owned by the admin, making them invisible to field reps due to sharing. |
